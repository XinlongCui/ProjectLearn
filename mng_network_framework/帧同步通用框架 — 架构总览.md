# 帧同步通用框架 — 架构总览

## 一、设计目标

将帧同步核心逻辑（帧缓冲、逻辑帧推进、预测、矫正、追帧、重连回放）固化为**与游戏无关的通用框架**，各玩法通过继承 + 泛型 + 回调接入，**只需关注自身协议格式和游戏逻辑**。

---

│  ├─ 连接协议层回调 (onFrameReceived → addServerFrame)          │

│                                                              │

│  ├─ setupDataHandler()       — onServerFrame → 逻辑层回调      │

               │
               ▼

│  └─ MngFrameCorrector  — 帧矫正器（服务器权威矫正）             │
└──────────────────────────────────────────────────────────────┘
               │
               ▼

│           MngBaseFrameSyncProtocol  (抽象基类)                 │

## 三、核心组件关系图

```
MngBaseFrameSyncDriver (驱动层)
 ├── clientSyncManager: MngClientFrameSyncManager (核心控制器)
 │    ├── frameBuffer: MngFrameBuffer (帧缓冲区)
 │    │    └── buffer: Map<frameIndex, MngFrameBufferItem>
 │    │         ├── clientFrame (客户端帧)
 │    │         └── serverFrame (服务器帧)
 │    ├── predictor: MngFramePredictor (帧预测器)
 │    ├── corrector: MngFrameCorrector (帧矫正器)
 │    │    ├── normalizeDirection() — 角度归一化钩子
 │    │    └── getPlayerKey()       — 玩家标识提取钩子
 │    ├── dataHandler: IMngFrameDataHandler (数据处理器)
 │    │    ├── onClientFrame()
 │    │    ├── onServerFrame()
 │    │    └── onServerFrameBatch()
 │    └── eventCallbacks: Map<EventType, Callback[]> (事件系统)
 │
 └── protocol: MngBaseFrameSyncProtocol (协议层)
      ├── onFrameReceived → Driver.addServerFrame()
      └── onReconnectReceived → Driver.reconnectGame()
```

## 四、数据模型继承图

```
MngBasePlayerInfo                   ← 各玩法扩展（如 skinId, level, campId）
     │
MngBaseFrameInfo                    ← 各玩法扩展（如 actionType, itemId, skillId）
     │
MngBaseFrameInfos<TInfo>            ← 一帧内单个玩家的全部数据
     │  simpleInfo: MngBasePlayerInfo
     │  infos: TInfo[]
     │
MngBaseFrameData<TFrameInfos>       ← 一帧内所有玩家的数据
     │  roomId, frameIndex
     │  frames: TFrameInfos[]
     │
MngFrameSendParams                  ← 发送帧数据参数，各玩法扩展额外字段
```

## 五、文件清单

| 文件 | 职责 |
|------|------|
| `mng_base_frame_data.ts` | 基础帧数据定义（PlayerInfo / FrameInfo / FrameInfos / FrameData） |
| `mng_frame_sync_config.ts` | 帧同步配置接口与默认值 |
| `mng_frame_sync_types.ts` | 枚举、接口、类型定义（状态、事件、回调、日志器） |
| `mng_frame_buffer.ts` | 帧缓冲区管理器（存储、查询、清理、丢帧检测） |
| `mng_frame_predictor.ts` | 帧预测器（线性插值预测，减少网络延迟感知） |
| `mng_frame_corrector.ts` | 帧矫正器（服务器权威数据矫正本地预测） |
| `mng_client_frame_sync_manager.ts` | 核心控制器（逻辑帧/渲染帧推进、对齐、追帧、批处理） |
| `mng_base_frame_sync_protocol.ts` | 协议层抽象基类（注册消息、发送帧数据、重连） |
| `mng_base_frame_sync_driver.ts` | 驱动层抽象基类（桥接协议层与核心控制器） |
| `mng_index.ts` | 统一导出 |
